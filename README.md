# 🐓 បក្សីកីឡា-24 Telegram Bot

Simple, always-active Telegram bot for bird-sport (បក្សីកីឡា) fans.

## Features
- 📅 Daily fight schedule
- 🏆 Live events
- 📊 Latest results
- 🎥 Stream links
- 🕐 24/7 active

## Deploy on Railway
1. Push to GitHub
2. railway.app → New Project → Deploy from GitHub
3. Add `BOT_TOKEN` variable
4. Deploy 🚀
